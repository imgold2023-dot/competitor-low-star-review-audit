# QA Bug Triage 样例页说明

创建时间：2026-07-04 Asia/Shanghai

用途：作为 Upwork 等自由职业平台 proposal 中可附加的公开能力证明。页面展示一个 2-4 小时 QA / bug triage paid trial 的交付形态，不是站外下单页，也不处理收款。

## 文件

- `qa-bug-triage-demo.html`：英文公开样例页。
- `qa-bug-triage-demo.zh-CN.md`：当前简体中文说明。

## 适用任务

- SaaS web app release QA；
- AI chatbot / AI product QA；
- role / permission / workflow bug triage；
- Playwright-ready manual regression pass；
- staging / sandbox / dummy data 环境下的小范围 paid trial。

## 交付物口径

- ranked bug table；
- reproduction steps；
- expected vs actual result；
- evidence note；
- coverage note；
- short regression checklist；
- optional Playwright-ready test outline。
