How I work

1. Narrow the task

Confirm the smallest useful deliverable and the expected result before changing code or writing a report.

2. Work from evidence

Use reproduction steps, public pages, test commands, screenshots, public reviews, or linked source files.

3. Deliver a concrete artifact

Provide a patch, test, Markdown report, or short implementation note with verification steps.

4. Stop at scope edge

If the task turns into a broader project, pause and clarify instead of silently expanding the work.
