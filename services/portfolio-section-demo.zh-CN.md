# 响应式作品集 Section Demo

用途：作为 Freelancer `Modern Responsive Portfolio Website` 这类小单的公开 proof asset。

公开页面：

- `https://imgold2023-dot.github.io/competitor-low-star-review-audit/services/portfolio-section-demo.html`

## 定位

这是一个平台安全的作品集 section 演示页，用来证明可以交付：

- 单页 portfolio section / one-page starter；
- 1-3 个项目卡片；
- case-study 文案区域；
- tech-stack tags；
- screenshot / mockup 区域；
- live / GitHub links；
- 桌面和移动端响应式布局。

## 平台安全边界

页面不包含：

- 站外联系方式；
- 站外付款入口；
- 站外下单入口；
- 表单；
- 邮箱；
- 支付、银行、钱包、KYC 或账号相关信息；
- 私有客户数据。

如果客户来自 Freelancer、Upwork 或其他自由职业平台，所有沟通、文件、订单和付款都应留在平台内。

## 商业用途

这不是正式产品页，也不是接单页。它是投递 proposal 时的能力证明，主要解决一个问题：

> 买家想要作品集网站时，单纯展示 QA / 研究 proof 不够贴近任务；这个页面能直接展示相关交付形态。

## 使用规则

- 在平台 proposal 中可作为 `Relevant public proof`。
- 不把它当成站外承接入口。
- 如平台规则禁止外部链接，则只描述 “I have a simple responsive portfolio-section demo ready”。
- 接单后仍以平台内 milestone、消息和文件交付为准。
